# 🔐 PassOP — Your Ultimate Password Vault

PassOP is a simple and user-friendly password manager web application that helps users store and manage passwords in one place.  
This project is built to demonstrate a basic full-stack application using React, Node.js, Express, and MongoDB.

----

## 🚀 Live Demo

Experience PassOP firsthand by visiting the live demo at:  
https://passop-1-6ga0.onrender.com/

----

# Why PassOP?

-PassOP is designed as a beginner-friendly full-stack project focused on simplicity and functionality.

-Easy to manage passwords using a clean interface.

-Frontend built with React for smooth user experience.

-Backend built using Node.js and Express.

-Data stored using MongoDB.

----

## 📌 Features

- **Password Management:**  
  Users can add, view, edit, and delete saved passwords.

- **Simple User Interface:**  
  Clean and responsive UI built using React.

- **Full-Stack Architecture:**  
  Separate frontend and backend for better project structure.

- **MongoDB Database:**  
  Password data is stored and managed using MongoDB.

- **Responsive Design:**  
  Works properly on desktop and mobile screens.

## 📂 Project Structure

**/backend**: Contains Node.js server code, API routes, and database logic.

**/backend/routes**: Contains API routes for handling password-related operations.

**/frontend**: React-based frontend application responsible for the user interface.

This separation between frontend and backend makes the project easier to understand and maintain.
